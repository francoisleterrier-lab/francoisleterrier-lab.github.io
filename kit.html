Gratuit · à coller

Ajoutez l'assistant IA à votre site. Ou affichez le crédit.

Deux petits bouts de code, prêts à coller. L'un ajoute un assistant de visibilité locale à votre site ; l'autre affiche un crédit discret. Aucune inscription, aucune dépendance.

1. Le widget « Assistant visibilité locale »

Idéal pour un partenaire, une association de commerçants, une CCI, ou vos propres clients : vos visiteurs posent une question, la réponse s'affiche sur mon moteur de réponses (avec leurs sources). Vous offrez un service utile, sans rien gérer.

Aperçu en direct
Code à coller (avant </body>)
<div data-fl-embed></div>
<script src="https://francoisleterrier.fr/embed.js" async></script>

Le widget renvoie vers francoisleterrier.fr/reponses.html avec la question pré-remplie. Un lien « Propulsé par François Leterrier » reste toujours visible.

2. Le crédit « Site réalisé par »

À placer dans le pied de page d'un site — un crédit sobre et un lien vers francoisleterrier.fr. Choisissez la version discrète ou la pastille.

Version discrète (texte)
Site réalisé par François Leterrier 
<a href="https://francoisleterrier.fr" target="_blank" rel="noopener">Site réalisé par François Leterrier</a>
Version pastille
Site réalisé par François Leterrier

Astuce : variez l'ancre d'un site à l'autre (« Site réalisé par François Leterrier », « Création du site : François Leterrier », « Community Manager & web : François Leterrier ») — c'est plus naturel pour Google.
